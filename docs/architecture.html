Browser Extension · Manifest V3 · v1

✨ AI Reading Companion

Select text on any webpage → get a floating Ask AI button → ask questions in an inline popover, grounded in the selected passage plus the page's title and URL. Answers stream in without leaving the page.

Data flow

Content Script injected into every page

  • Listens for mouseup / selectionchange (debounced)
  • Reads window.getSelection() + range.getBoundingClientRect()
  • Renders button & popover inside a Shadow DOM — isolated from page CSS/JS
  • Sends the question, streams the answer back into the popover
▼ chrome.runtime.connect port · { selection, title, url, question }

Background Service Worker the brain

  • Loads API key + provider/model from chrome.storage.local
  • Builds the grounded prompt (system + context + question + history)
  • Picks a provider via the providers/ abstraction
  • Streams tokens back over the port as CHUNK → DONE
▼ HTTPS · stream: true

AI Provider configurable

  • Claude — Anthropic Messages API (SSE content_block_delta)
  • OpenAI — Chat Completions API (SSE choices[].delta)
  • Same StreamProvider interface — swapping is a settings change

Non-destructive by design

What it reads from the page

getSelection().toString() range.getBoundingClientRect() document.title location.href

Only the highlighted passage is sent to the AI — never the whole page.

What it injects

A single host <div> with an open Shadow DOM holding the button + popover.

The page's own DOM, scripts, and state are never modified. Shadow DOM stops CSS leaking in either direction.

The click, step by step

Select text — content script computes the selection rect.
✨ Ask AI button appears just below the selection, clamped on-screen.
Popover opens — selection shown as a context chip, with quick actions + input.
Submit — content script opens a port and posts the AskRequest.
Background builds the prompt, picks the provider, starts the stream.
Tokens stream back as CHUNKs → rendered as live markdown.
Follow-up stays in the same popover — a mini-conversation per passage.
